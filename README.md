# TA_PhishSense

PhishSense merupakan suatu sistem deteksi web phishing menggunakan ekstensi browser dan aplikasi desktop berbasis deep learning dengan algoritma CNN. Phishsense terdiri dari 2 komponen yaitu:
1. Ekstensi browser
2. Aplikasi desktop

## Set-up Ekstensi Browser

1. Siapkan atau copy folder `phishsense_extension` ke directory local
2. Buka browser (berbasis chromium) dan masuk ke menu ekstensi atau manage extension
3. Aktifkan developer mode
4. Pilih load unpacked
5. Pilih folder `phishsense_extension` yang sudah ada di local
6. Lihat apakah ekstensi sudah terpasang dengan nama "TA - Phishing Detection Extension"
7. Klik extensi-nya dan pastikan pop up muncul, jika ada error tidak apa apa, yang penting pop up sudah muncul

## Set-up Aplikasi Desktop

1. Download file pada link gdrive berikut
> https://drive.google.com/file/d/16pCP42hdcLSkIMvYLIKieiilc4BgjcIn/view?usp=sharing
2. Extract file tersebut sehingga menjadi folder
3. Jalankan (atau klik 2x) file `PhishSense.exe`
4. Tunggu sampai dashboard muncul

## Cara menggunakan

1. Buka browser yang sudah dipasangi ekstensi
2. Masukkan link suatu web
3. Tunggu notifikasi muncul di browser
4. Untuk cek history, dapat dilakukan di aplikasi browser (dashboard)
